## Overview

**LinkedIn Shamer** is a desktop utility designed to monitor user activity and foster productivity through *intelligent recruiter-style notifications*.  
It detects inactivity or engagement with blacklisted apps (games, social media, streaming) and triggers **randomized recruiter pop-ups** to humorously “remind” you to stay focused.

The app includes tray controls for pausing, resuming, and checking why you’re being pinged.  
Built with Electron and Node.js, it integrates seamlessly into background workflows.

---

### Why Use Linkedin Shamer?

This project helps users and developers lock in through automated notifications that shame you for being inactive or unproductive.

**Core features include:**

 **Activity Monitoring:** Detects inactivity or blacklisted app usage to trigger context-aware notifications.  
 **Randomized Alerts:** Sends varied recruiter messages to keep engagement fresh and funny.  
 **Tray Controls:** Easy access to Pause, Resume, and “Why am I being pinged?” actions.  
 **System Integration:** Lightweight Electron app designed for smooth background operation.

## Getting Started

### Prerequisites

This project requires:

- **Programming Language:** JavaScript  
- **Package Manager:** npm  
- **Platform:** Windows 10/11  

---

### Installation

Build LinkedIn-Shame-App from the source and install dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourname/LinkedIn-Shame-App
   ```
2. **Navigate to the project directory:**
   ```bash
   cd LinkedIn-Shame-App
   ```
3. **Install Dependencies:**
   ```bash
   npm install
   ```

## Usage
Run the project with:

```bash
npm start
```

When running, the app minimizes to your **system tray**.  
Right-click the tray icon to access:

- ▶️ **Resume** — start recruiter notifications  
- ⏸️ **Pause** — stop notifications  
- ❓ **Why am I being pinged?** — explains the trigger (Idle / Blacklisted App)  
- 🚪 **Quit** — exit the app
